## ✨ Special Effects

### 1. **Neon Glow on Hover**
```css
hover: {
  boxShadow: `0 0 20px ${neon-green}99`
}
```
- Cards glow green when hovered
- Futuristic interaction
- Satisfying feedback

### 2. **Accent Border Glow**
```css
hover: {
  borderColor: theme.colors.accent
}
```
- Border turns neon green
- Clean transition
- Modern effect

### 3. **Subtle Background Gradient**
```css
from-purple-900/20 to-black/40
```
- Adds depth without being obvious
- Keeps it professional
- Similar to Dark theme's gradient
