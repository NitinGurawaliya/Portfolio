# Custom Domain Mapping Feature

## Overview
This feature allows users to connect their custom domains (e.g., `nitin.com`) to their portfolio generated by our app, instead of using the default subdomain pattern (`nitin.devfolio.app`).

## Use Case
- User buys a domain: `nitin.com`
- User creates portfolio on our platform: `nitin.devfolio.app`
- User wants visitors to `nitin.com` to see their portfolio
- Portfolio remains hosted on our infrastructure, but accessible via custom domain

---

## Technical Architecture

### High-Level Flow
1. User adds custom domain in dashboard
2. System provides DNS configuration instructions
3. User configures DNS records at their registrar
4. System verifies domain ownership via DNS challenge
5. System provisions SSL certificate (via Let's Encrypt or Vercel)
6. System maps custom domain to user's portfolio
7. Portfolio accessible via custom domain

### Components Involved
- **Database**: Store domain mappings and verification status
- **API Routes**: Domain CRUD operations, verification
- **Middleware**: Route custom domains to correct portfolios
- **DNS Verification**: TXT record or CNAME verification
- **SSL/TLS**: Automatic certificate provisioning
- **UI Components**: Domain management interface
- **Edge Functions**: Handle custom domain routing

```prisma
  @@index([domain])
  @@index([verified])
}
```

## Technical Implementation Details

### 1. DNS Verification Implementation

```typescript
// lib/domain-verification.ts

import dns from 'dns/promises';

export async function verifyDomainTXT(
  domain: string, 
  expectedToken: string
): Promise<boolean> {
  try {
    const records = await dns.resolveTxt(`_devfolio-verification.${domain}`);
    
    // records is array of arrays: [['token1'], ['token2']]
    const flatRecords = records.flat();
    
    return flatRecords.includes(expectedToken);
  } catch (error) {
    console.error('DNS verification failed:', error);
    return false;
  }
}

export async function verifyDomainARecord(
  domain: string, 
  expectedIP: string
): Promise<boolean> {
  try {
    const addresses = await dns.resolve4(domain);
    return addresses.includes(expectedIP);
  } catch (error) {
    console.error('A record verification failed:', error);
    return false;
  }
}
```

### 2. Middleware Implementation

```typescript
// src/middleware.ts

import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';
import { prisma } from '@/lib/prisma';

// Cache for custom domain lookups (in-memory or Redis)
const domainCache = new Map<string, { username: string; timestamp: number }>();
const CACHE_TTL = 5 * 60 * 1000; // 5 minutes

export async function middleware(req: NextRequest) {
  const hostname = req.headers.get('host') || '';
  const url = req.nextUrl;
  
  // Skip for localhost, API routes, static files
  if (
    hostname.includes('localhost') ||
    hostname.includes('127.0.0.1') ||
    url.pathname.startsWith('/api/') ||
    url.pathname.startsWith('/_next/') ||
    url.pathname.startsWith('/static/')
  ) {
    return NextResponse.next();
  }
  
  // Check if this is your main domain
  const mainDomain = process.env.NEXT_PUBLIC_APP_DOMAIN;
  if (hostname === mainDomain || hostname.endsWith(`.${mainDomain}`)) {
    return NextResponse.next(); // Normal routing
  }
  
  // This might be a custom domain
  const normalizedDomain = hostname.replace(/^www\./, ''); // Remove www
  
  // Check cache first
  const cached = domainCache.get(normalizedDomain);
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    url.pathname = `/${cached.username}`;
    return NextResponse.rewrite(url);
  }
  
  // Query database
  const customDomain = await prisma.customDomain.findUnique({
    where: {
      domain: normalizedDomain,
      verified: true
    },
    include: {
      user: {
        select: { username: true }
      }
    }
  });
  
  if (customDomain) {
    // Cache the result
    domainCache.set(normalizedDomain, {
      username: customDomain.user.username,
      timestamp: Date.now()
    });
    
    // Rewrite to user's portfolio
    url.pathname = `/${customDomain.user.username}`;
    return NextResponse.rewrite(url);
  }
  
  // No custom domain found, show error page
  return new NextResponse('Domain not configured', { status: 404 });
}

export const config = {
  matcher: [
    '/((?!api|_next/static|_next/image|favicon.ico).*)',
  ],
};
```

### 3. API Route: Add Custom Domain

```typescript
// src/app/api/custom-domain/route.ts

import { NextRequest, NextResponse } from 'next/server';
import { getServerSession } from 'next-auth';
import { prisma } from '@/lib/prisma';
import { randomBytes } from 'crypto';

export async function POST(req: NextRequest) {
  // 1. Authentication
  const session = await getServerSession();
  if (!session?.user?.id) {
    return NextResponse.json(
      { error: 'Unauthorized' },
      { status: 401 }
    );
  }
  
  // 2. Parse request
  const { domain } = await req.json();
  
  // 3. Validate domain format
  if (!isValidDomain(domain)) {
    return NextResponse.json(
      { error: 'Invalid domain format' },
      { status: 400 }
    );
  }
  
  // 4. Normalize domain (remove www, lowercase)
  const normalizedDomain = domain.toLowerCase().replace(/^www\./, '');
  
  // 5. Check if domain already exists
  const existing = await prisma.customDomain.findUnique({
    where: { domain: normalizedDomain }
  });
  
  if (existing) {
    return NextResponse.json(
      { error: 'Domain already in use' },
      { status: 409 }
    );
  }
  
  // 6. Generate verification token
  const verificationToken = `devfolio-verify-${randomBytes(16).toString('hex')}`;
  
  // 7. Create custom domain record
  const customDomain = await prisma.customDomain.create({
    data: {
      domain: normalizedDomain,
      userId: session.user.id,
      verificationToken,
      verified: false,
      sslStatus: 'pending'
    }
  });
  
  // 8. Return DNS configuration instructions
  return NextResponse.json({
    success: true,
    domain: customDomain,
    dnsRecords: [
      {
        type: 'A',
        name: '@',
        value: process.env.APP_IP_ADDRESS,
        ttl: 3600
      },
      {
        type: 'CNAME',
        name: 'www',
        value: process.env.NEXT_PUBLIC_APP_DOMAIN,
        ttl: 3600
      },
      {
        type: 'TXT',
        name: '_devfolio-verification',
        value: verificationToken,
        ttl: 3600
      }
    ]
  });
}

function isValidDomain(domain: string): boolean {
  const domainRegex = /^(?:[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?\.)+[a-z0-9][a-z0-9-]{0,61}[a-z0-9]$/i;
  return domainRegex.test(domain);
}
```

## Security Considerations

### 1. Domain Hijacking Prevention
- **Verification Required**: Always verify domain ownership before activation
- **TXT Record Method**: Most secure verification method
- **Token Rotation**: Change verification tokens periodically

### 2. Rate Limiting
- Limit domain additions per user (e.g., 3 domains per account)
- Rate limit verification attempts (prevent brute force)
- Rate limit DNS lookups (prevent DoS)

### 3. Input Validation
- Validate domain format strictly
- Prevent SQL injection on domain input
- Sanitize domain names before storage
- Blacklist reserved domains (localhost, internal IPs)

### 4. Access Control
- Only domain owner can modify settings
- Require re-authentication for domain removal
- Log all domain-related actions

### 5. SSL/TLS
- Force HTTPS for all custom domains
- Use HSTS headers
- Monitor certificate validity

## Performance Optimization

### Caching Strategy
```typescript
// Use Redis for production
import { Redis } from '@upstash/redis';

const redis = new Redis({
  url: process.env.REDIS_URL,
  token: process.env.REDIS_TOKEN
});

async function getCustomDomain(domain: string) {
  // Try cache first
  const cached = await redis.get(`domain:${domain}`);
  if (cached) return JSON.parse(cached);
  
  // Query database
  const customDomain = await prisma.customDomain.findUnique({
    where: { domain },
    include: { user: true }
  });
  
  if (customDomain) {
    // Cache for 5 minutes
    await redis.setex(
      `domain:${domain}`,
      300,
      JSON.stringify(customDomain)
    );
  }
  
  return customDomain;
}
```
