## Why You're Getting This IP

### Current Code Flow:

```typescript
// src/lib/vercel-api.ts
export async function getVercelRecommendedIP() {
  // 1. Check if APP_IP_ADDRESS env var is set
  const envIP = process.env.APP_IP_ADDRESS;

    return { ip: envIP }; // Use env var if set
  }
  
  // 2. If not set, use default Vercel IP
  const defaultIP = '76.76.21.21'; // Vercel's standard IP
  return { ip: defaultIP };
}
```

1. ✅ System checks `APP_IP_ADDRESS` env var first
2. ❌ If not set, uses default: `76.76.21.21`
3. ✅ This is Vercel's standard IP - it's correct!
